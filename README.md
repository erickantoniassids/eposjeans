# Loja EPOS Jeans — protótipo visual

Protótipo de front-end da loja virtual da épos. Arquivo único (`index.html`) com fotos, logo e scripts embutidos.

## Publicar no GitHub Pages

1. Envie `index.html` para a raiz do repositório.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
